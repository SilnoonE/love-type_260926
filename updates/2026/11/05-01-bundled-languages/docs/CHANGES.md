# 2026-11-05 변경 기록

## 최종 방식

언어 선택 → 선택값 저장 → Activity 재생성 → 앱에 포함된 번역 문자열 표시.

한국어가 기본입니다. 영어·일본어·중국어 간체·스페인어를 선택할 수 있습니다. Google 번역 모델을 내려받아 준비하는 이전 구현은 최종 배포 대상이 아닙니다.

| 파일 | 현재 역할 |
|---|---|
| `Localization.kt` | 저장한 언어를 읽고 Android 언어 설정을 적용하며 JSON에서 표시할 문구를 찾음 |
| `LanguageSettingsDialog.kt` | 5개 언어 선택, 적용 및 취소 UI |
| `LanguageSettingsViewModel.kt` | 선택 언어를 즉시 적용하는 상태 처리 |
| `assets/ui_translations.json` | 앱에 함께 포함되는 번역 표 |
| `res/values*` | 각 언어의 Android 화면 문자열 |
| `MainActivity.kt` | 언어 설정 진입과 기존 테스트·카드 화면 연결 |
| `DailyCardAdapter.kt`, `DailyCardShareRenderer.kt` | 카드 목록 및 공유 이미지 표시 |
| `app/build.gradle.kts` | ML Kit 번역 의존성 없음. 버전 코드 12, 버전명 12.0 |

기존 원본 질문과 저장 카드 스냅샷을 표시용 복사본으로 변환하는 구조를 유지합니다. `TranslationCache.kt` 등 남아 있는 보조 파일도 원본과 동일하게 보관했습니다. 이번 보관 작업에서 불필요해 보이는 파일을 임의로 정리하지 않았습니다.

## 코드 보존 원칙

사용자 최신 코드를 다시 설계하거나 번역 문구를 자동으로 고치지 않았습니다. 배포 준비에서 원본 변경은 버전 번호 두 줄뿐입니다. 공개 사본은 운영 광고 ID 3개 파일을 테스트 ID로 치환하며, 앱의 서명키와 개발 PC 설정을 포함하지 않습니다.

## 이전 작업과 정정

이전 작업에서 준비했던 버전 11은 Google ML Kit 모델 다운로드 방식이었습니다. 사용자가 내장 번역 방식으로 수정한 현재 코드와 다르므로 최종 출시 파일로 사용하면 안 됩니다.

이전에 별도로 게시했던 루트 개인정보처리방침은 ML Kit 방식에 대한 설명이라 현재 코드와 맞지 않아 이번 커밋에서 제거했습니다. 기존 커밋 이력은 재작성하지 않았습니다. 기존 날짜별 개발 기록과 PDF는 보존했습니다.

스토어 설명은 사용자가 직접 작성한 내용이므로 임의 수정하지 않습니다. 이전 작업에서 저장된 설명·데이터 보안 초안은 버전 12의 출시 승인 내용으로 간주하지 않습니다.
