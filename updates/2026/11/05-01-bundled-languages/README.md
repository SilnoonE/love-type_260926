# 버전 12: 앱에 저장된 번역으로 즉시 언어 전환

2026-11-05에 사용자가 직접 수정한 최신 앱을 보관한 누적 기록입니다. 이전 업데이트 폴더와 커밋은 보존합니다.

| 항목 | 내용 |
|---|---|
| 앱 | 기존 연애 성격 테스트 |
| 버전 | versionCode 12 / versionName 12.0 |
| 언어 선택 | 한국어(기본), 영어, 일본어, 중국어 간체, 스페인어 |
| 방식 | 앱에 포함된 JSON 번역 데이터를 읽어 즉시 적용 |
| 출시 상태 | 서명된 AAB 준비 완료. 버전 12는 아직 Play Console 업로드·심사 제출되지 않음 |

## 이번 변경

- 사용자가 Google ML Kit 실시간 번역 및 모델 다운로드 의존성을 제거했습니다.
- 언어 설정에서 언어를 선택하고 적용하면 설정을 저장하고 화면을 다시 생성합니다.
- `ui_translations.json`의 내장 번역을 사용합니다. 언어 모델 다운로드나 번역 준비 대기 단계가 없습니다.
- 기존 테스트, 오늘의 질문, 답변 카드와 즐겨찾기 구조는 최신 원본 그대로 보관했습니다.
- 이번 배포 준비에서 원본 앱에 직접 수정한 것은 버전 번호 두 줄뿐입니다. 이전 파일에 버전 코드 11이 사용되어 최신 파일은 12로 준비했습니다.
